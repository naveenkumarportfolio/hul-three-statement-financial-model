# Hindustan Unilever Limited (HUL) – Three-Statement Financial Modelling Project

An independent finance portfolio project focused on analysing Hindustan Unilever Limited (HUL) and developing an integrated three-statement financial model using Microsoft Excel.

> **Project Status: Working Draft – Validation Required.** Historical financial figures and statement linkages identified during review still need correction and reconciliation. This project should not be presented as a fully verified financial model until these checks are completed.

##  Project Overview

The objective of this project is to understand HUL's financial performance and learn how the three primary financial statements connect within an integrated financial model.

##  Project Objectives

- Analyse the company's historical financial performance.
- Understand the relationship between the three financial statements.
- Build an integrated three-statement financial model.
- Prepare a five-year financial forecast using assumptions.
- Review financial trends and present findings through a financial analysis report.

## 📊 Model Components

### 1. Income Statement
Analysis of revenue, expenses, profitability and key financial performance measures.

### 2. Balance Sheet
Analysis of assets, liabilities and shareholders' equity, including Balance Sheet checks.

### 3. Cash Flow Statement
Analysis of operating, investing and financing cash flows, including cash reconciliation.

### 4. Financial Analysis Report
A written report covering financial performance, modelling methodology, assumptions and key observations.
